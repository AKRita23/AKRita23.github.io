I've worked in security for 12 years, most of it at Amazon and AWS, with a stint leading product security at SunPower. My focus now is identity for AI agents and other non-human workloads: who an agent is, what it is allowed to touch, how that access narrows as work passes from one agent or company to the next, and how to shut it off when an agent goes wrong.

I also build agents that do security work, like reading service code and writing threat models that a reviewer can check line by line.
